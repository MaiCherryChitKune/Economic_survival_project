# 🏫 Virtual Campus Tour

An interactive 360° virtual campus tour that allows prospective students 
and visitors to explore President University's facilities from anywhere.

## 🚀 Key Features

- **360° Virtual Tour**: Immersive panoramic views of campus locations
- **Easy Navigation**: Simple forward and back arrow buttons to move 
between locations
- **Location Display**: Shows the current location name while touring

## 🗺️ Campus Locations Available

- 🏫 Campus Lobby
- 📚 Library
- 🛋️ Fablab
- ☕ Cafe
- 🏡 Interior Design Classroom
- 🏊 Swimming Pool
- 🎮 Game Development Classroom
- 🏢 Building B (Classroom)
- 🏌️ Golf Club
- 🏢 Building A (Classroom)
- 📖 Classroom for Law Students

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Momento360 (360° panoramic viewer)
